# CTEC-450-102-Capstone-Final-Machine-Learning-Defense
This capstone project explores how machine learning models can be attacked and defended. A machine learning model has been built to conduct adversarial attacks and learn strategies to defend against them.

The attack used was an FGSM (Fast Gradient Sign Method) attack. The goal of this attack is to  generate subtle perturbations to input data, such as images, that fool neural networks into misclassifying them while remaining nearly imperceptible to humans.
